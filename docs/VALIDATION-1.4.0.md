## 实际下载

单独创建固定MeTube镜像的新后台，不挂载用户数据、不发布网络端口、不导入浏览器Cookie。初始化固定PyPI引擎、部署当前抖音插件、重启并确认加载后，通过API下载合成短HLS测试源，用ffprobe检查：

| 选择 | 测试源 | 输出 |
| --- | --- | --- |
| 2K / 1440 | 多档720/1440/2160 | 1440p，AAC音轨 |
| 4K / 2160 | 多档720/1440/2160 | 2160p，AAC音轨 |
| 音频 | 同一测试源 | MP3，无视频流 |
| 4K / 2160 | 仅720p | 720p，AAC音轨；未放大 |

测试容器和自身匿名数据卷在结束时移除。复现：`bash distribution/tests/run-quality-smoke.sh`。该夹具允许临时容器获取其内部合成源，未更改正式后台的内部地址保护。
