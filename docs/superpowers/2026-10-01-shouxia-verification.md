# 收下 1.0 验收记录

2026-10-01，Apple M4 / macOS 26.6.2。

## 实现

原生 SwiftUI 主窗口与菜单栏 QuickPanel；粘贴/拖入链接；视频画质和 MP3 模式；真实队列进度；取消、重试、开始等待任务；下载记录与本地文件打开、Finder 定位、拖出。使用既有本机 MeTube 服务，无新增付费依赖。

纸白、墨绿、薄荷绿统一主窗口与图标。输入焦点、禁用按钮、拖入提示、解析状态均有反馈；支持系统减少动态效果偏好。没有将不受 API 支持的暂停按钮放入界面。

## 已验证

- 本机 release 编译、ad-hoc 签名校验、用户 Applications 安装、桌面入口。
- 链接校验、分享文字提取、480p 参数、直链源画质/容器、音频参数、JSON 解码、文件路径范围和符号链接、API 错误、任务 URL 身份及四种操作请求的回归测试。
- Swift 6 核心模块编译和真实 MeTube history 解码。
- GUI 提交 W3C Sintel trailer，实际保存 4,372,373 字节 MP4；Finder 正确选中文件。
- GUI 提交 MDN flower.mp4 的仅音频模式，实际保存 21,036 字节 MP3。
- 关闭窗口后重新唤起可以恢复主窗口。
- 无活动任务时停止容器，界面转为离线；点击重新连接后容器恢复，界面显示已就绪。
- 错误输入出现可读提示；完成文件不存在时禁用文件操作。
- 独立代码审查和原生界面截图审查；接口身份问题在真实操作中发现并修复后复审。

## 联调修复

1. MeTube 固定高度筛选会排除高度未知的媒体直链：已知视频文件直链使用源画质和容器。
2. History 禁用 URLSession 缓存，避免保留旧队列状态。
3. MeTube 所谓 API ids 是网址队列键，并非提取器视频编号：所有任务操作和 SwiftUI 身份统一为 URL。
4. 移除测试记录后核验视频文件内容未变。
5. 菜单栏图标保持固定，列表合并为单一 URL 身份序列，移除提交后的布局动画；复测后台完成状态能更新到窗口，完成后筛选按钮正常。具体系统框架触发点未单独隔离。
6. 真实待开始任务以 URL 取消后，pending 和 queue 均无此任务。

## 验证边界

菜单栏 QuickPanel 已实现并编译，自动化工具未暴露系统菜单栏状态项，未完成该入口的鼠标端到端测试。文件拖入/拖出未做跨应用鼠标拖拽验收。未逐个平台测试抖音、Bilibili、X 或需要登录的链接。

W3C 样片在首次成功后后续请求触发 403；错误已如实呈现，没有绕过挑战。改用 MDN 公开样片完成音频测试。既有用户记录和文件保留，新增的 trailer.mp4、flower.mp3 和 flower.webm 是本次测试样片。

后台仍依赖这台电脑的既有 Colima/Docker，不是跨电脑通用安装包。退出应用保持后台任务运行，帮助界面有说明。
