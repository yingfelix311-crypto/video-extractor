# 收下 Implementation Plan

> **For agentic workers:** Use subagent-driven-development for backend unit and review; root builds native UI and packaging.

**Goal:** Working independent Mac video download application connected to existing MeTube.
**Architecture:** SwiftUI UI and menu-bar share one observable Store. Foundation HTTP client decodes MeTube history. Runtime bootstrap uses fixed executable arguments, never interpolates user URLs into shell code.
**Tech Stack:** Swift, SwiftUI, AppKit, Foundation; no package downloads.

## Global Constraints
Localhost only. Preserve existing downloaded files/history. Only user-requested URLs submitted. Honest API states, no fabricated progress. Chinese UI, keyboard navigation, reduced motion.
