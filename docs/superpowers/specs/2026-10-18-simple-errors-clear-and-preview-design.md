# 简单失败原因、明确清空入口、可缩放预览

用户要求先解释 Cookie 与多个浏览器关系，再执行交互修改；已在对话说明。用户明确委托安排预览临界值，继续当前任务分支，不再要求一轮形式审批。用户停止剪辑验证：不再进行导出、播放或素材验证实验，仅实施并编译本轮预览交互。

- Cookie 是选定浏览器/配置里的对应网站会话，可能属于访客；复制链接来源、系统默认浏览器和该来源独立。不混读多个浏览器。不从读取、Cookie 名称或提取成功推断账号登录。
- 最新相同引擎/网址交替对照：空 jar 两次失败，当前 Chrome 任务会话两次成功，均经过官方移动分享页备用路径。网站登录状态核查未成功，因此不宣称登录是必要条件；也不倒推历史任务。
- 主窗口、快捷输入始终提供带文字的“清空”，空值禁用。有文本时单击或 Esc 清空并回到输入框；不影响已提交任务、画质、目录。快捷窗口空值时 Esc 保持原关闭行为。
- 主流程失败提示仅一句简短原因，不显示长解释、原始错误/复制入口，不自动弹出浏览器设置。同一失败已有可见任务行时不再重复顶部提示；详细原因留在任务数据/日志。明确本机读取、网站拒绝、格式、服务、保存问题；未知时不猜登录或权限。
- 剪辑预览增加减小、滑杆、放大与适应窗口。等比显示，最小预览区高度 180 pt，最大 min(720 pt, 窗口高度×70%, 宽度对应画布比例的最大高度)，最低上限不小于180。默认320，缩放不修改画布、裁切、导出尺寸或选区。窗口缩小时渲染值夹紧，不产生溢出。
- 保留当前原生视觉、已有偏好、媒体与记录；只构建一次最终原生更新后安装，保留旧版备份。ad-hoc 更新可能要求系统重新确认原已授予的文件访问，不放宽签名。
