# Video Extractor 可靠下载补齐

用户已明确要求实现上一轮报告中全部缺口。保持现有 SwiftUI、MeTube、AVFoundation 与当前视觉，不更换架构、不发布 Windows、不更改 Stacher。

链接层：保留原始链接与规范链接；受信任抖音网页的单一数字 modal_id 转 /video/id。普通短链交给引擎跟随，不盲转图集/直播。错误分类及可执行中文恢复。视频默认 any，兼容 MP4 作为明确选择，音频仍 MP3。网络设置仅允许无凭证 HTTP/HTTPS/SOCKS 代理、Referer、User-Agent，不开放任意命令；Cookie 仅用户选取 Netscape 文件，校验、导入、状态、删除均可用，不读取账户。

任务层：提交时立即出现本地操作行、阶段与取消解析；取消调用 MeTube cancel-add 并对账，超时和取消不自动重复提交。重试重新规范化、使用明确参数；保留保存目的地，失败旧记录仅新请求成功后清除。以唯一请求 folder 对账，持久化未决提交，下次启动恢复。

交互层：视频/音频输入参数与任务筛选分开，全部/进行中/已完成/失败并显示数量；快捷输入显示参数和结果，不自动消失。设置集中 Cookie、网络、后台依赖诊断和引擎更新。原始错误折叠、可复制，恢复按钮对应具体问题。

后台网络参数仅通过 loopback 的 MeTube API；若现有容器未允许参数覆盖，使用备份原容器的可回滚迁移开启，保留挂载、镜像运行层和所有原配置；未知运行配置明确拒绝，不能重建丢失数据。下载、更新、Cookie 写入与配置迁移不能重叠。

验收：有意义的 Swift 核心与 HTTP stub 回归、旧保存/剪辑/更新测试；构建签名与安装；实际错误样本验证可识别且需 Cookie 提示明确，不声称无 Cookie 可以下载。使用公开媒体直链验证下载保存。Cookie 成功访问私人平台需用户自己的有效 Cookie，不能伪造。
