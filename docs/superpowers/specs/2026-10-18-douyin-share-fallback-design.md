# 抖音分享页备用解析

用户已要求修复给定抖音链接及自动使用本人浏览器登录信息。本次是该下载流程的兼容修复，沿用既有授权、Cookie 域名筛选、独立任务文件及本地后端。

已验证：权限重新绑定后可读到 62 条未过期的相关 Cookie；Safari 可播放目标视频；yt-dlp 原有 detail API 仍失败。带相同 Cookie 的 Android 分享页返回目标 `aweme_id`、230.412 秒时长及播放地址；不带登录信息的分享页没有该数据。CDN 对该地址的 Range 请求返回 206、video/mp4 及 MP4 文件头。

选择 yt-dlp 官方插件机制：原提取器成功时直接沿用；仅其 Fresh cookies 错误触发一次手机版分享页读取。匹配精确视频 ID，仅采用页面提供的 http(s) 播放地址，不改写水印参数，不向媒体 CDN 复制登录 Cookie。不执行网页脚本，不使用第三方解析服务。缺少匹配数据或请求失败时明确报告备用解析失败，不无限重试。

其他选项：只更新 yt-dlp（上游当前代码仍相同）；增加完整浏览器运行时（依赖和交互成本较高）。本次采用已实测得到数据的分享页路径。

插件独立于原生二进制，避免再次破坏刚修复的 macOS 权限绑定。源文件及安装脚本进入仓库；运行副本放在下载卷的隐藏应用目录，并通过容器内 yt-dlp 标准插件目录加载。现有原地引擎升级保留插件；容器整体替换后需重跑安装脚本。

验收：夹具测试覆盖精确 ID、空列表、非法地址、JSON 格式、原流程成功/非 Cookie 错误、字段缺失及 Cookie 不复制；分享文案链接提取已在原问题中确认，真实应用提交该分享链接，显示完成，输出文件由 ffprobe 验证音视频流及约 230 秒时长。实际文件规格以 ffprobe 为准，备用分享页可能仅提供部分画质。
