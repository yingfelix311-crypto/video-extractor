# Mac 原版分发

用户已确认取消 Windows，只提供与当前 Mac 原版一致的产品。仓库保持私有，仅有读取权限的用户可以下载。

不修改 Shouxia 的 SwiftUI、AVFoundation、参数、菜单栏、快捷输入、任务与更新实现。首次发行包复制当前已安装的原生 App，记录整包哈希；提供原版程序及首次环境安装脚本。

安装层提供固定版本的 Colima 0.10.3、Docker 29.8.2、Lima 2.2.0；建立 metube profile（2 CPU / 2 GiB / 20 GiB / VZ / virtiofs）、固定 MeTube 镜像 digest，初始化下载缓存与 127.0.0.1:8081 端口。新环境使用当前原版的 yt-dlp 2026.09.27.232945，之后仍由原版更新逻辑维护。

已有环境只检查并复用，不覆盖配置、导入历史或新建订阅。不上传任何用户目录、日志、账户信息、虚拟机磁盘或容器状态。其他工具冲突时明确停止，不能擅自覆盖。

提供 README 下载入口、安装/停止/卸载说明、校验值、第三方许可证、原版一致性说明。分发为未公证的私有测试版；不能声称已经在干净 Mac 完整验收。
