# 演示项目第三方素材

- `assets/gsap.min.js`：GSAP 3.14.2，保留原始版权头；遵循 [GSAP Standard License](https://gsap.com/standard-license)。仅用于演示时间线，不是 App 的新增运行依赖。
- `assets/fonts/font-3.ttf`：现有项目 Manrope 字体，许可证见同目录 `Manrope-OFL.txt`。
- 中文字形由渲染机器系统字体提供；项目不包含系统字体文件。
- 产品图标沿用项目已有资源。测试视频为 FFmpeg 生成图；实机截图仅含该测试任务。

第三方材料的许可证独立适用，不随项目自有源码许可改变。
