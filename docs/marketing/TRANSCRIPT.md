# 30 秒演示字幕与范围

这是原生 1.4.1 的**实机截图剪辑**，无配音和背景音乐。界面中的视频来自 FFmpeg 自制测试图，不含用户媒体、账号或浏览器 Cookie。每一段按阅读所需时长停留，不表示真实下载耗时。

| 时间 | 画面 / 字幕 |
| --- | --- |
| 00:00–00:03 | Video Extractor：把喜欢的片段，带回来。 |
| 00:03–00:10 | 粘贴链接，点击提取。视频 / MP3，最佳画质或指定画质上限。 |
| 00:10–00:16 | 保存后，打开或截取。任务保留保存位置，可直接打开本地文件。 |
| 00:16–00:21 | 默认保留原视频比例。预览与导出共用所选画布。 |
| 00:21–00:27 | 选好画面比例和时间。21:9 示例，选中 00:02–00:08，导出为新文件。 |
| 00:27–00:30 | 留下一段，随时回看。到 GitHub 下载测试版。Apple Silicon，macOS 14+。 |

演示实际完成了链接提交、独立 MeTube 后端下载和本地保存，并操作了剪辑比例和时间选择。成片未展示或声称本次导出成功；导出功能的既有验证见版本验证文档。2K / 4K 是画质上限，不会把演示的 720p 测试片升格为高清。

隔离构建仅改动 Bundle ID、偏好 / 日志 / 缓存位置、服务端口与更新容器目标；产品 UI、下载和剪辑算法保持原版本。下载结果从隔离容器复制到独立演示缓存后由 App 保存；过程包含一次演示 App 重启。它不是干净 Mac 首装验收。原安装 App 和生产后台未被替换。

HyperFrames 可编辑项目在 [`demo-project/`](demo-project/)。开发者使用 Node.js 22+、FFmpeg 和固定的 HyperFrames 0.8.171 重现；普通用户安装 App 不需要这些演示制作依赖。项目使用本机中文系统字体，跨机器重现时字形可能略有区别，不分发系统字体文件。
