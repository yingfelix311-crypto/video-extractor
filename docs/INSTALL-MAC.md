# Mac 安装与运行

## 1.4.2 候选版：首次打开自动准备后台

适用于 Apple Silicon（M 系列）及 macOS 14+。下载新版本的 **Native macOS arm64 ZIP**，完整解压，将唯一的 `Video Extractor.app` 放进“应用程序”后打开即可。GitHub 的 Source code ZIP 不是安装包。

应用自带 Colima、Docker CLI、Lima（含 `lima` 和 `limactl`），无需 Homebrew、Docker Desktop、Python、Node 或 FFmpeg。第一次打开会自动：

1. 核对运行组件和现有环境，复用兼容组件；冲突时说明原因，不覆盖其他工具。
2. 准备本机虚拟机并下载固定 MeTube 镜像。
3. 安装指定下载引擎、部署解析插件，并检查服务和下载依赖。
4. 显示“下载服务已就绪”后允许提取。

首次需要联网，可能需要几分钟。窗口底部会显示当前步骤；不要在准备期间反复打开另一个副本。断网或退出后，再次打开或点“重新连接”可继续；已下载的镜像层和初始化记录会保留。准备失败不会被视为安装成功，也不会把未就绪后台放行给下载任务。

**当前公开旧版仍为 1.4.1**：旧包需要双击 `安装原版.command`。以上单 App / 自动准备流程适用于合入本次修改后重新构建的 1.4.2 安装包，不能通过只更新源码来修复已经下载的旧 ZIP。

## 提取视频和音频

粘贴单视频链接或整段分享文字，确认保存位置，点击“提取”。选择“音频”输出 MP3。先使用最佳画质、默认关闭的网站访问辅助。

4K / 2K 取决于源视频是否提供相应格式。失效链接、源站限制、网络问题和网站解析器变化仍可能导致个别任务失败；后台可用不代表所有网站或所有链接都能下载。快手当前缺少解析器，暂不支持。

## 系统首次信任

候选发行仍为 ad-hoc 签名，未获 Apple 公证。macOS 可能要求在“隐私与安全性”中确认信任。仅在确认来自本仓库时按系统流程操作，不要关闭 Gatekeeper。正式无障碍分发需要维护者完成 Developer ID 签名、公证与独立干净 Mac 验收，见 [发布流程](RELEASE-MAC.md)。

## 浏览器辅助：可选

公开链接先直接尝试。网站明确要求登录或需要尝试已有网站会话时，在“设置 → 网站访问辅助”开启并选择实际浏览器配置，保存后重试。

- Chrome / Edge 可能请求钥匙串授权，由用户在系统窗口确认。
- Safari 仅在实际读取被拒绝时，才为当前 App 开启完全磁盘访问权限并重启应用。
- Cookie 不一定表示已登录，也不能保证网站接受。可选择“本次不读取浏览器”重试。
- 不要将 Cookie、密码或浏览器数据库发送给维护者。高级设置可手动导入 Netscape Cookie 文件（最多 1 MB）并清理会话。

## 运行组件与存储

| 内容 | 位置 / 配置 |
| --- | --- |
| App | 用户选择的应用程序目录；安装包只含一个 App |
| 内置安装组件 | App 内 `Contents/Resources/BackendInstaller`，无需单独拖走 |
| 用户运行组件 | `~/.local/bin`、`~/.local/share/lima` |
| 版本 | Colima 0.10.3、Docker CLI 29.8.2、Lima 2.2.0 |
| 虚拟机 | Colima `metube`，2 CPU、2 GiB 内存、20 GiB 虚拟磁盘上限 |
| 服务 | Docker `colima-metube` context、`metube` 容器；仅 `127.0.0.1:8081` |
| 缓存与后台记录 | `~/Downloads/MeTube` 及其 `.metube` 子目录 |
| 偏好、初始化恢复记录与日志 | `~/Library/Application Support/Shouxia`、当前用户偏好 |

安装器不带作者的 Cookie、历史、媒体、订阅或虚拟机磁盘。兼容的已有后台会保留；不重新安装其他用户已有容器的下载引擎。解析插件只在没有活动任务时更新。安装器并发运行时会等待用户稍后重试，避免两个初始化互相覆盖。

## 排查与恢复

- 首次准备失败：检查网络，点“重新连接”。应用会保留具体失败阶段并将命令输出写到 `~/Library/Application Support/Shouxia/backend.log`。
- 服务未连接：应用会尝试恢复连接；也可手动重新连接。
- 系统未允许虚拟化：在本机正常打开应用重试；受限制的远程执行或沙盒可能阻止虚拟机运行，不应据此断定芯片不支持。
- 运行组件冲突：保留现有工具，按错误中的具体路径核对版本，不要盲目覆盖或删除。
- 8081 端口被其他服务占用：释放冲突后再重试；安装器不会覆盖其他服务。
- 下载成功但保存失败：选择可写文件夹，点“重试保存”，无需重新下载。

需要从终端检查时，以实际安装位置替换下面的 App 路径：

```sh
bash '/Applications/Video Extractor.app/Contents/Resources/BackendInstaller/安装原版.command' --check
```

`--check` 只核对运行组件、后台和插件，不启动或修改后台。`--backend-only` 可手动继续后台初始化；它不会复制或打开第二份 App。

退出 App 不会终止后台已经提交的下载。停止资源使用：

```sh
~/.local/bin/colima stop --profile metube
```

再次打开 App 即可重新启动后台。卸载客户端只需退出 App 后将其移入废纸篓，不会删除媒体。共享运行组件和缓存应核对并备份后再清理。

## 验证边界

自动化覆盖包内组件完整性、单 App ZIP、签名、后台初始化中断恢复、冲突保护和依赖检查。测试夹具不等于干净物理 Mac 的首次安装；发布前仍须完成独立机器从匿名下载到首次提取、重启恢复的验收。不同网站成功率应按有效样例记录，不作全站可用承诺。
