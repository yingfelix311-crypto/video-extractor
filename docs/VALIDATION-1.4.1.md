# 1.4.1 画面比例与自定义尺寸验证

本轮范围是常用画面比例、自定义比例 / 像素宽高，以及相应的预览和导出一致性。没有重复无关的剪辑、倍速和时间轴全量回归；1.4.0 的非剪辑与安装记录保留在 [上一版验证记录](VALIDATION-1.4.0.md)。

## 已完成

- `bash Shouxia/test-clip-aspects.sh --export`：比例几何、精确 21:9、自定义输入校验、模式转换、无效草稿隔离和加载素材后的模型检查通过。覆盖 NaN / 无穷、零 / 负值、奇数像素、超限、互质大尺寸和窄长比例。
- 自动生成短横屏与带旋转信息的测试素材；原尺寸、21:9、自定义 5:4、1280×1024 的实际 MP4 导出检查了显示尺寸、时长、音轨、中心内容及黑边。不使用用户视频做导出测试。
- 安装后的已下载文件入口：比例菜单、原尺寸默认、21:9、自定义 5:4 与 1280×1024 更新、无效 1281 像素宽度的简短提示和禁用操作均已核对。预览缩放和“适应窗口”不改变输出尺寸。
- 界面截图检查发现分段选择器的标题被固定宽度挤压，隐藏多余视觉标题并保留辅助功能名称后重新构建、安装和检查，确认修复。
- 优化的原生 arm64 / macOS 14 目标构建及 strict 签名校验通过；20 项安装器测试通过；独立代码审查没有待修复发现。
- 完整安装包重新解压，`--verify-only` 与已有后台 `--check` 通过。原生文件清单、源提交和 SHA256 随发行附件提供。
